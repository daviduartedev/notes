# spec/code-style.md

- TypeScript **strict** (`noUncheckedIndexedAccess`).
- Zod na fronteira HTTP.
- Sem `any` injustificado.
- Enums e identificadores de domínio em **inglês**; UI, docs, commits em **português**.
- `workspaceId` nunca lido do body.
- Arquivos pequenos e focados; sem camadas de repositório genérico.
- Imports de tipo com `import type`.
